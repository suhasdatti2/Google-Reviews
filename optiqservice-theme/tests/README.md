# Optiq AI test suites

Plain Node, no framework. Run each from this folder:

```bash
npm install liquidjs        # once, for render-knowledge.js only
node render-knowledge.js    # renders the Liquid knowledge payload, asserts valid JSON
node test3-degraded.js      # broken / missing / truncated payloads never kill the widget
node test5-ui.js            # drives the real markup: open, type, Enter, tools, reset, close
node test6-general.js       # questions the store does not cover + arithmetic over real prices
node test7-remote.js        # the model path, with the endpoint stubbed
```

`render-knowledge.js` deliberately emulates Shopify's error semantics: filters
that raise (like `image_url` on a nil image) replace the whole output tag with
error text rather than returning a value. A forgiving stub is what let a broken
payload reach production once already.

`live-payload.json` is generated by `render-knowledge.js` from `store-live.json`,
which mirrors the real catalogue shape — including the two products that have no
image, since that is what broke the payload.
